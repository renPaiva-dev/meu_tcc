Importar bairros (GeoJSON)

Com os bairros importados, o app descobre a zona do usuário pela localização. Use um FeatureCollection em WGS84 (EPSG:4326), por exemplo a malha de bairros publicada pelo IBGE ou pela prefeitura, com uma propriedade para o nome do bairro e outra para a zona. Bairros com o mesmo nome são atualizados.
